# تنظيم أعمال الدائرة الرابعة — الإصدار الثاني

موقع مستقل يعمل على **GitHub Pages** دون Lovable، مستوحى بصريًا من شكل البوابات الإدارية السعودية من حيث الأخضر والأبيض والتبويبات والبطاقات، **دون أي شعار أو ادعاء ارتباط بوزارة أو جهة حكومية**.

## أهم الميزات

### 1) القضايا ومحاضر الجلسات
- جدول قضايا اليوم التالي مع اختيار التاريخ، وبيانات الدعوى والأطراف ورقم القضية والوقت.
- إدراج نص ضبط الجلسة السابقة كاملًا، وملخص الجلسة، وسبب الرفع، واقتباس حرفي يدعم السبب؛ الاقتباس يجب أن يطابق المحضر قبل الحفظ.
- إضافة وتعديل وإزالة القضايا، بما فيها القضايا التي تضاف بعد الحصر الأولي.
- إظهار اسم من أدخل القضية، وآخر من عدلها، وسجل التغييرات في قاعدة البيانات.
- القاضي يراجع ملخص كل قضية ويعتمدها؛ أي تغيير في بيانات القضية يلغي اعتمادها.
- صفحة «تقرير الجلسات» مع **اعتماد التقرير اليومي** بعد اعتماد جميع القضايا، ثم حفظه كصورة PNG أو مشاركته عبر خيار مشاركة الملفات في الجهاز. يتلاشى اعتماد التقرير تلقائيًا عند تعديل قضية بعده.

### 2) المهام والتذكيرات
- إضافة مهمة في فئات: قضية تحتاج تصحيحًا، بريد يتطلب ردًا، تذكرة، متابعة، وأخرى.
- عنوان، وصف، رقم قضية/تذكرة اختياري، أولوية، تاريخ مطلوب.
- إظهار اسم من أضاف المهمة بخط صغير وتاريخ الإضافة، مع تعديل المهمة وإزالتها.
- القاضي يضع علامة ✓ **تم الإنجاز**، أو يعيد فتح المهمة؛ ويظهر اسم من أنجزها.
- قائمة مفتوحة ومنجزة والجميع، مع البحث ومؤشر المهام العاجلة.
- إشعار داخل الموقع عند إضافة مهمة أو تعديلها أو إنجازها، وكذلك عند إضافة قضية أو تعديلها أو اعتمادها.

### 3) اختيار الاسم والدخول

- اختر اسمك من الأسماء الثلاثة المعتمدة. ينشئ الموقع هوية للمتصفح عند أول دخول، ويعرض معرّفها في شاشة الانتظار.
- يعتمد مسؤول المشروع الجهاز بعد مطابقة المعرّف مع صاحبه عبر وسيلة موثوقة. يضبط المسؤول الاسم الكامل والدور من جدول `profiles` ثم يفعّل `is_active`. الاسم الذي يختاره مقدم الطلب مجرد طلب للمراجعة.
- بعد الاعتماد اضغط «التحقق مجددًا». يحتفظ المتصفح بجلسة الدخول عند إغلاقه. يتطلب مسح بيانات المتصفح أو تسجيل الخروج أو استخدام متصفح جديد اعتمادًا جديدًا.
- القاضي زياد محمد البابطين (`judge`)، وأمينا السر يحيى محمد إبراهيم بكري وعبد الرحمن يحيى علي الشريف (`secretary`). يقتصر اعتماد القضايا والتقارير وإنجاز المهام على القاضي.

## الاتصال والحفظ المشترك

يستخدم الموقع مشروع Supabase المخصص للدائرة الرابعة `fgthgaawdccdhejogchw` على GitHub Pages. يضم ملف `config.js` عنوان المشروع ومفتاح النشر العام. تبقى صلاحية قراءة بيانات القضايا والمهام والكتابة فيها محكومة بسياسات RLS واعتماد الجهاز. راجع مخطط المشروع الحالي قبل أي ترحيل. ملفات SQL الأصلية مرجع لإعداد نسخة جديدة.


## الإشعارات والتلخيص

- إشعارات الإضافة والتحديث والإنجاز **داخل الموقع** تتزامن بين الحسابات؛ ويمكن طلب إذن إشعارات المتصفح عند فتح الصفحة.
- إشعارات الدفع إلى الجوال عند إغلاق الموقع **غير مفعلة**؛ تتطلب خدمة Web Push في مرحلة مستقلة.
- `database/noon_reminder.sql` اختياري لتوليد إشعار ظهر اليوم داخل الموقع على Supabase Cron (بعد تفعيله).
- زر «تلخيص بالذكاء الاصطناعي» يحتاج وظيفة `supabase/functions/summarize-minutes/index.ts` ومفتاح API سري على الخادم، وقرارًا مستقلًا بشأن جواز معالجة المحاضر. ما يعمل من دون AI هو «استخراج تحضيري» أولي يحتاج مراجعة، وليس تحليلًا قانونيًا معتمدًا.

## العمل اليومي

- الساعة 10:00 ص: حصر **قضايا الغد فقط** من تقاضي.
- الساعة 11:30 ص: مطابقة جدول الغد وتحديث المستجدات.
- الساعة 12:00 ظهرًا: الاطلاع على التقرير وإصدار الصورة عند الحاجة.
- نحو نهاية الدوام: مطابقة ثانية وإضافة القضايا المؤجلة إلى الغد بعد وقت الظهر.
- صباح يوم الجلسة: تحقق أخير من أي تغيير طارئ في جدول تقاضي.

## ملفات المشروع

- `index.html` و`styles.css`: الواجهة الإدارية الجديدة المتجاوبة.
- `app.js`: القضايا والمهام والصلاحيات والرسائل وإخراج صورة التقرير.
- `config.js`: إعداد الاتصال بالقاعدة (الواجهة خالية من مفاتيح سرية).
- `database/setup.sql`: الجداول الأساسية والصلاحيات.
- `database/upgrade_v2.sql`: المهام، والمراجعات، واعتماد التقرير وإلغاء اعتماده عند تعديل القضايا.
- `database/noon_reminder.sql`: تنبيه الظهر الاختياري.
- `supabase/functions/summarize-minutes/index.ts`: التلخيص الذكي الاختياري على الخادم.
- `manifest.webmanifest` و`assets/favicon.svg`: إعدادات إضافة الموقع للشاشة الرئيسية والأيقونة المجردة غير الرسمية.
